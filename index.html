Patch Policy: Efficient Embodied Control via Dense Visual Representations

Continuous Plug/Unplug Demo (2x)

Abstract

Lightweight robot policies often compress pretrained visual features into global vectors, discarding spatial detail, while large vision-language-action models achieve strong performance at substantial computational cost. We introduce Patch Policy and show that simply feeding frozen Vision Transformer patch features into a small transformer policy achieves state-of-the-art performance on precise manipulation benchmarks with a fraction of the parameters of large vision-language-action models. Across four simulated and three real-world manipulation benchmarks, Patch Policy with a frozen ViT-S DINOv2 encoder improves average normalized performance by 54% over the same policy using global CLS features and by 18% over OpenVLA-OFT, while using just 0.7% of OpenVLA-OFT’s total parameters and achieving 11 ms inference latency on an H200 GPU. Patch Policy further demonstrates zero-shot generalization to unseen objects on one additional simulated and one real-world benchmark. Through controlled comparisons, we find that dense patch features improve precise manipulation, whereas the tested spatial compression methods consistently degrade performance. A study of five pretrained encoders reveals that visual representation strongly affects manipulation performance, with performance linked to the ease of extracting object position and orientation. Patch Policy provides an efficient approach to precise manipulation and a unified framework for studying how visual representations translate into closed-loop control.

Method

In this work, we aim to give visuomotor policies direct access to the dense, spatially-rich features that large-scale Vision Transformer pre-training already provides. Instead of compressing each observation into a single global vector such as a pooled feature or a ViT CLS token, which discards the fine-grained detail needed for precise manipulation, Patch Policy feeds the full grid of patch features from a frozen, pretrained ViT to a lightweight transformer-based policy. With VQ-BeT, the patch tokens pass through a block-causal self-attention mask, full attention within a frame and causal across frames, and the action head reads out the last patch token of each frame to predict a chunk of actions. With Diffusion Policy, a separate sequence of noisy action tokens attends to itself causally, then cross-attends to the patch tokens and a diffusion step token, masked so each action step always sees the step token but only sees patches from frames up through that step.
